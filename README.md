# restrict-discipline

DSH（DeepSeek Harness）行为规范插件：约束 Agent 的文件操作与系统行为，保护敏感配置，降低上下文 Token 消耗。

## 功能

规则按类别组织，类别说明：**强制约束**（违规自动拦截）、**Token 节约**（软约束，不拦截）、**Token 节约补充**（软约束，不拦截）、**编码纪律**（软约束，不拦截）、**会话记忆**（软约束，不拦截，由插件自动执行）。

| # | 规则 | 类别 | 说明 |
|---|------|------|------|
| 1 | 文件分类 | 强制约束 | 新建文件必须放入对应目录（`scripts/`、`log/`、`docs/`、`memory/` 等），禁止在项目根目录创建文件 |
| 2 | `.env` 保护 | 强制约束 | 禁止读取/修改/删除/搜索项目根目录的 `.env`；违规访问被拦截并记录到 `log/<会话名>/env-access.log` |
| 3 | 代理保护 | 强制约束 | 禁止修改系统代理及 git/npm/yarn/pnpm/pip 的 proxy 配置；违规命令被拦截并记录到 `log/<会话名>/denials.log` |
| 4 | 操作留痕与复用 | 强制约束 | 执行有实际效果的操作前先用 `find_operation` 按关键词检索 `scripts/` 是否已有相同脚本，命中则直接运行复用；未命中再执行，并用 `record_operation` 保存为 `scripts/<会话名>/` 下可双击运行的脚本（`.cmd` + `.ps1`），维护 `index.md` 索引；通用流程（发布、构建、CI 触发等）首次执行必记录，后续会话优先复用 |
| 5 | 目录外确认 | 强制约束 | 修改/删除项目目录以外的文件时请求用户确认；只读访问默认放行 |
| 6 | 会话摘要与跨会话复用 | 强制约束 | 每轮对话结束自动将会话总结（含本会话已记录脚本清单，自动过滤运行时噪音）写入 `memory/<会话名>.txt`（覆盖旧摘要）；新会话首次内容解析时由规则 16 自动注入相关历史记忆，无需手动读取 `memory/`；复用之前会话执行过的脚本（配合规则 4 的 `find_operation`） |
| 7 | 遍历排除 | 强制约束 | `grep`/`glob` 遍历项目内容时主动排除 `.env` |
| 8 | 长输出落盘 | Token 节约 | 大输出先重定向到 `log/<会话名>/`，再按需 grep/read 关键片段 |
| 9 | 按需读取 | Token 节约 | 大文件用 `offset`/`limit` 分段读取，先 grep 定位；内容未变不重复整读 |
| 10 | 合并命令 | Token 节约 | 独立命令合并为一次 pwsh 调用（`;` 分隔），独立工具调用并行发出 |
| 11 | 简洁回复 | Token 节约 | 要点式短句，不重复规则原文、不整段回显命令输出 |
| 12 | 避免重复验证 | Token 节约 | 状态未变化时不重复执行/读取；确需复验时合并为一条命令完成 |
| 13 | 批量编辑 | Token 节约补充 | 同一文件的多次小修改合并为一次 read + 多次 edit；相关改动合并为一次 git 提交 |
| 14 | 失败收敛 | Token 节约补充 | 同一目标操作因沙箱/环境失败时最多尝试 2 种替代方式，之后停止并询问用户或改策略 |
| 15 | Karpathy 编码准则 | 编码纪律 | 编码/改动前遵循 [andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills)：(1) 先想后写——明确假设、有歧义先问、说明权衡；(2) 简单优先——只写最少必要代码；(3) 外科手术式修改——只改必须改的、保持既有风格；(4) 目标驱动——转成可验证标准并循环验证 |
| 16 | 会话记忆自动注入 | 会话记忆 | 新会话首次内容解析时自动检索 `memory/` 中与当前任务最相关的历史摘要（BM25 排序 Top3、每条 600 字截断、排除本会话自身摘要）注入到上下文的【历史记忆】块，每会话仅一次；后续轮次不重复检索，注入内容随会话历史保留，无需再次回忆；同时在会话中追加一条思考提示（reasoning 块，列出已回忆文件）与自标注注记 |

## 安装

从 GitHub 安装（推荐）：

```bash
dsh plugin --profile web add github:refyon/restrict-discipline
```

## 启用 / 禁用

1. 打开 Web UI → **设置 → 插件**
2. 找到 **restrict-discipline（行为规范）** 卡片：勾选 = 启用（默认），取消勾选 = 禁用
3. 配置写入命名空间 `restrict-discipline.enabled`（`$DSH_HOME/settings.yaml`）

禁用后所有拦截/确认/留痕/摘要行为暂停；工具仍可见，但调用会提示已禁用。

## 行为说明

- **目录外修改**：`write`/`edit` 工具及 pwsh 写入/删除命令（`New-Item`、`Set-Content`、`Out-File`、`Copy-Item`、`Move-Item`、`Remove-Item`、重定向等）目标在项目目录外时请求确认；
- **只读放行**：`read`/`read_image`/`grep`/`glob`/`Get-Content` 等只读操作默认放行，不打扰。
- **会话记忆自动注入**：新会话首次内容解析时，插件在 `system-prompt/assemble` 阶段自动检索 `memory/` 中相关历史摘要（以首条用户消息为查询、BM25 排序、Top3、每条 600 字截断、排除本会话自身摘要），追加进运行时上下文快照（【历史记忆】块）；按会话 id 只执行一次，后续轮次跳过，会话销毁时清理标记。注入成功时同步向会话追加一条"回忆提示"消息：思考块（reasoning）列出已回忆的文件、文本为自标注系统注记，让首轮思考内容可见。

## 开发

```bash
# 规则核心冒烟测试（零依赖）
node test/smoke-host.mjs
```

### 目录结构

```
lib/enforce.js   # 规则核心（纯逻辑、无依赖、可独立测试）
lib/search.js    # 脚本检索：倒排索引 + BM25（规则 4 find_operation）
lib/memory.js    # 会话记忆检索与注入块渲染（规则 16）
lib/index.js     # host 插件：设置注册、工具、摘要、pre-execute 接线
lib/client.js    # 浏览器卡片：设置 → 插件 的启用/禁用开关
cordis.patch.yml # bundle 补丁：将 host 行插入 profile 组成
```
